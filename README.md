## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Ashutoshkuma8271/portfoliofullbanner.git

# Navigate to project directory
cd portfoliofullbanner

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production

```bash
npm run build
```

## 🌐 Deploy to Vercel

This repository is pre-configured for one-click deployment to [Vercel](https://vercel.com/):

1. Push this repository to your **GitHub** account.
2. In your Vercel Dashboard, click **Add New Project** and select your GitHub repository.
3. Vercel will automatically detect Vite:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**. SPA client routing, asset caching headers, and clean URLs are handled automatically via `vercel.json`.
